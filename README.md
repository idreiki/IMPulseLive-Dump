# IMPulse Live (Dota 2 AI) — Разбор защиты и полный дамп

Полный реверс-инжиниринг и снятие всей защиты с **IMPulse Live** (Dota 2 AI помощник по пикам). Автор заявлял, что проект приватный, «никогда не будет опенсурсом» и защищён компиляцией через Nuitka в машинный код x86-64.

По факту — проект был полностью разобран до винтика, из бинарников вытащены все захардкоженные ключи, снята DRM-лицензия с киллсвитчем, а скомпилированные `.pyd` модули восстановлены в **100% чистый Python** без единого нативного бинарника.

---

## Что было сделано

### 1. Анализ архитектуры и защита

Внутри установщика и папки `_internal` лежало стандартное Nuitka-окружение:
- **Движок UI:** Flask локальный сервер + GDI+ прозрачный клик-сквозной (click-through) оверлей поверх клиента Доты.
- **Модули логики:** Собраны через **Nuitka C-компилятор** в нативные PE32+ DLL (`.pyd`) под Windows x64 Python 3.12 (`dataset_updater.pyd`, `security_guard.pyd`, `pick_evaluator.pyd`, `find_all_heroes.pyd`, `hero_grid_locator.pyd`, `ui_bundle.pyd`).
- **UI бандл:** `ui_bundle.pyd` содержал распаковщик ресурсов веб-интерфейса из Base64 + zlib.

---

### 2. «Шифрование» и слитый Stratz API токен

Вся статистика матчей и меты парсится через GraphQL API сервиса **Stratz**. Разработчик попытался спрятать свой личный API-токен:

1. В константах модуля `dataset_updater.pyd` прямо открытым текстом лежал мастер-ключ:
   ```python
   SECRET_KEY = b'IMPulseLiveSecretKey2026_DotaVision'
   ```
2. Алгоритм «криптографии» оказался банальным циклическим побитовым сдвигом с XOR:
   ```python
   plain = bytes([((b - (7 + (i % 13))) % 256) ^ SECRET_KEY[i % len(SECRET_KEY)] 
                  for i, b in enumerate(base64.b64decode(enc_token))])
   ```
3. Результат расшифровки — валидный JWT токен Stratz, в который зашит реальный **SteamID автора**:
   ```json
   {
     "Subject": "61843030-1f9c-42ad-bdaf-9edda758b0ab",
     "SteamId": "1891508217",
     "APIUser": "true",
     "iss": "https://api.stratz.com"
   }
   ```
   * *Dota 2 Friend ID автора:* `1891508217`  
   * *SteamID64:* `76561199851773945`

### 3. SecurityGuard & DRM (Киллсвитч через GitHub)

В приложении был встроен модуль удалённого контроля `security_guard.py`. Как выяснилось при разборе, своего сервера у автора нет — вся «инфраструктура» завязана на публичный репозиторий GitHub:

1. **Маскировка эндпоинта:**
   URL конфига был замаскирован в бинарнике 4-байтовым XOR-ключом:
   ```python
   _K = b'\x9cO\xb2\x17'
   def _dx(b: bytes, k: bytes = _K) -> str:
       return bytes([b[i] ^ k[i % len(k)] for i in range(len(b))]).decode('utf-8')
   ```
   После снятия маски получаем реальный адрес «сервера»:
   ```
   https://raw.githubusercontent.com/twirlspro/IMPulse-Live/main/data/app_config.json
   ```
   * **GitHub автора:** [`twirlspro`](https://github.com/twirlspro)
   * **Репозиторий:** `IMPulse-Live`

2. **Механизм удалённой блокировки (Kill-Switch):**
   Каждые `7200` секунд фоновый поток `SecurityGuard` опрашивает этот JSON-файл:
   - **Рубильник (`sync_enabled`):** Если автор выставляет `"sync_enabled": false`, приложение мгновенно блокируется у всех пользователей с сообщением из поля `status_message` (*«Приложение временно приостановлено разработчиком»*).
   - **Принудительное устаревание (`min_version`):** Сравнение текущей версии `2.0.0` с минимальной версией из конфига через `parse_semver()`.
   - **Оффлайн-ловушка (`OFFLINE_GRACE_PERIOD = 172800`):** Жёсткий тайм-аут на **48 часов**. Если софт не может достучаться до GitHub дольше двух суток, он блокируется и требует подключения к сети.
   - **Локальный кэш лицензии:** Записывался в файл `.license_cache` с XOR-шифрованием на байт `0x5A`:
     ```python
     payload = f"{timestamp}|{sha256(timestamp + '|IMPULSE_SEC_2026')[:16]}"
     ```

3. **Что сделано в Standalone:**
   - Все сетевые запросы к GitHub заблокированы.
   - Фоновый поток `heartbeat` отключён.
   - `is_locked()` принудительно возвращает `False`, а `check_security()` — `True`.
   - Приложение работает полностью автономно и вечно в оффлайне.

### 4. Реконструкция ядра в 100% Pure Python

Так как Nuitka компилирует код под конкретную версию CPython (3.12 x64), привязка к бинарникам `.pyd` делала проект непереносимым. Была проведена полная декомпиляция и обратная разработка алгоритмов:

#### `pick_evaluator.py` (Оценка драфтов)
Восстановлен оригинальный математический аппарат ранжирования героев:
- **Формула преимущества:**
  $$\text{Score} = 0.40 \times \text{Meta} + 0.25 \times \text{Synergy} + 0.25 \times \text{Counter} + 0.10 \times \text{Personal}$$
- **Нелинейная нормализация** винрейтов через гиперболический тангенс:
  ```python
  norm = math.tanh((winrate - 0.5) / 0.08)
  ```
- Коэффициент достоверности выборки:
  $$\text{Confidence} = \frac{\text{Matches}}{\text{Matches} + 10.0}$$
- Учёт стадий игры: Early / Mid / Late с весами ранней агрессии и лейта.

#### `find_all_heroes.py` (Компьютерное зрение)
- Захват экрана через `mss`.
- Мульти-масштабный поиск иконок героев в слотах пика через OpenCV (`cv2.matchTemplate` с метрикой `TM_CCOEFF_NORMED` и порогом `> 0.65`).
- Распознавание цветовых полосок слотов игроков (Radiant / Dire) через HSV-профили оттенков (`SLOT_PLAYER_HUES`).

#### `hero_grid_locator.py` (Win32 Оверлей)
- Прозрачный клик-сквозной оверлей на Win32 API (`WS_EX_LAYERED | WS_EX_TRANSPARENT`).
- Восстановлены точные относительные координаты сетки пика для всех **127 героев Dota 2**.

## Структура репозитория

```text
├── app.py                  # Главный Flask бэкенд и контроллер потоков
├── dataset_updater.py      # Синхронизация меты со Stratz GraphQL
├── find_all_heroes.py      # Детект героев на экране через OpenCV
├── pick_evaluator.py       # Математический движок ранжирования пиков
├── hero_grid_locator.py    # Win32 GDI+ клик-сквозной оверлей
├── security_guard.py       # Обезвреженный DRM-модуль
├── ui_bundle.py            # Сервис раздачи фронтенда
├── ui/                     # Исходный Web UI (HTML, CSS, Vanilla JS)
├── assets/                 # Иконки способностей, предметов и героев Dota 2
├── data/                   # Базовые таблицы меты и координат героев
├── requirements.txt        # Зависимости Python
└── run.bat                 # Запуск в 1 клик
```

## Запуск

1. Установите зависимости:
   ```bash
   pip install -r requirements.txt
   ```

2. Запустите проект:
   ```bash
   run.bat
   ```
   *или напрямую:*
   ```bash
   python app.py
   ```

Интерфейс откроется в окне вебвью, а оверлей автоматически привяжется к окну Dota 2. Никаких подписок, ключей и киллсвитчей.
