# IMPulse Live (Dota 2 AI) — Разбор защиты и полный дамп

Разобрал «приватный» софт IMPulse Live за вечер. В чате автор громко заявлял, что софт *«никогда не будет опенсурсом»*, компиляция через Nuitka в машинный код x86-64 делает его неприступным, а на любые намёки уверенно кидал *«Напишешь как получится 😂»*. Ну вот, получилось.

По факту — классический вайбкодинг на коленке, завёрнутый в Nuitka с расчётом на то, что никто не умеет открывать бинарники. Вся «защита» рухнула за пару часов: личный токен Stratz слит, киллсвитч на бесплатном гитхабе обезврежен, а скомпилированные `.pyd` модули переписаны в **100% чистый Python**.

---

## Что было сделано

### 1. Анализ архитектуры: «Dota 2 AI» на Flask и картинках

Открыл установщик и распаковал внутренности `_internal`:
- **«Искусственный интеллект»:** Никаких нейросетей там нет и близко. Обычный локальный сервер на Flask, который дёргает API со статистикой и считает простейшую формулу в 4 строчки.
- **Оверлей:** Прозрачное click-through окно на древнем Win32 GDI+, рисующее прямоугольники поверх Доты.
- **Скомпилированные модули:** Автор просто натравил Nuitka на 6 питоновских файлов (`dataset_updater`, `security_guard`, `pick_evaluator`, `find_all_heroes`, `hero_grid_locator`, `ui_bundle`), наивно полагая, что машинный код спрячет всё.

---

### 2. «Шифрование» и эпичный слив личного токена

Вся статистика матчей и мета тянутся из GraphQL API сервиса **Stratz**. Автор очень хотел спрятать свой личный токен, но получилось как всегда:

1. Прямо в константах скомпилированного `dataset_updater.pyd` в открытом виде лежал «секретный» ключ:
   ```python
   SECRET_KEY = b'IMPulseLiveSecretKey2026_DotaVision'
   ```
2. Алгоритм «шифрования» — шедевр криптографии от ChatGPT:
   ```python
   plain = bytes([((b - (7 + (i % 13))) % 256) ^ SECRET_KEY[i % len(SECRET_KEY)] 
                  for i, b in enumerate(base64.b64decode(enc_token))])
   ```
   Сдвиг на 7 плюс остаток от деления на 13 и XOR. Серьёзно?

3. Расшифровываем строку и получаем чистый JWT токен от Stratz, в котором заботливо прошит реальный SteamID автора:
   ```json
   {
     "Subject": "61843030-1f9c-42ad-bdaf-9edda758b0ab",
     "SteamId": "1891508217",
     "APIUser": "true",
     "iss": "https://api.stratz.com"
   }
   ```
   * **Dota 2 Friend ID автора:** `1891508217`
   * **SteamID64:** `76561199851773945`

*Привет Вадиму, можешь добавлять в друзья в Доте.*

### 3. Серверная безопасность? Нет, бесплатный GitHub

Разработчик гордо рассказывал про серверную авторизацию и защиту. На деле своего бэкенда у проекта **нет вообще**:

1. Адрес «сервера» спрятан через XOR-маску `_K = b'\x9cO\xb2\x17'`:
   ```
   https://raw.githubusercontent.com/twirlspro/IMPulse-Live/main/data/app_config.json
   ```
   Вся «инфраструктура» проекта — это один JSON-файлик в публичной репе `twirlspro/IMPulse-Live` на GitHub.

2. **Киллсвитч:** Каждые 7200 секунд программа стучится в этот JSON. Если Вадим меняет `"sync_enabled": true` на `false`, приложение падает с плашкой *«Технические работы»*.
3. **Ловушка на 48 часов:** Жёсткий оффлайн-лимит (`172800` сек). Если у юзера нет интернета двое суток — прога блокируется.
4. **Кэш лицензии:** Файлик `.license_cache` с валидацией через SHA-256 и XOR на байт `0x5A`:
   ```python
   payload = f"{timestamp}|{sha256(timestamp + '|IMPULSE_SEC_2026')[:16]}"
   ```

В версии **Standalone** весь этот цирк вырезан под корень: запросы заблокированы, проверки всегда возвращают `True`, софт работает автономно и вечно.

### 4. Реконструкция в 100% Pure Python

Зависеть от чужих `.pyd` файлов под конкретный Python 3.12 x64 было лень, поэтому модули были полностью отреверсены и переписаны на чистый Python:

- **`pick_evaluator.py`:** Тот самый «AI». По факту — школьная формула с коэффициентами:
  $$\text{Score} = 0.40 \times \text{Meta} + 0.25 \times \text{Synergy} + 0.25 \times \text{Counter} + 0.10 \times \text{Personal}$$
  Плюс сглаживание через гиперболический тангенс `math.tanh((winrate - 0.5) / 0.08)`. Вот и весь искусственный интеллект.
- **`find_all_heroes.py`:** Захват экрана через `mss` и банальный поиск шаблонов через `cv2.matchTemplate(..., TM_CCOEFF_NORMED)`. Плюс парсинг полосок слотов по таблице HSV-оттенков.
- **`hero_grid_locator.py`:** Восстановлена вся координатная сетка драфта на 127 героев Доты. Исправлен кривой вызов Win32 API, ронявший `pywebview`.

## Оценка защиты

**Криптография и ключи:** 1/10. Зашить ключ `IMPulseLiveSecretKey2026_DotaVision` открытой строкой в бинарник, зашифровать им свой личный токен через XOR со сдвигом, да ещё и вшить туда свой персональный SteamID — это премия Дарвина. Снимается за 10 минут любым HEX-редактором или бинарным grep'ом.

**Серверная инфраструктура:** 2/10. Сервера нет. Вообще. Весь удалённый контроль и «лицензирование» держится на одном сыром JSON-файле на бесплатном GitHub. Заблокировать чужой GitHub аккаунт или спуфнуть DNS — и вся «защита» умирает. А в оффлайне софт просто позорится лимитом в 48 часов.

**Обфускация и упаковка:** 3/10. Автор подумал: *«Скомпилю в Nuitka — никто не разберёт»*. Но Nuitka не защищает строки, не скрывает архитектуру CPython и оставляет все сигнатуры методов и констант как на ладони. Внутри не было даже базового UPX или упаковщика строк, не говоря уже о виртуализации или контроле целостности памяти.

**Архитектура софта:** 4/10. Обычная связка Flask + WebView + OpenCV. Идея неплохая, но называть взвешенную сумму винрейтов со Stratz «Dota 2 AI» — это сильный маркетинг. Код полон костылей и хардкода, которые автор сгенерировал в AI без ручного ревью.

**Итого:** типичный пример того, как человек без понимания базовой безопасности пытается закрыть коммерческий продукт. Попытка напугать Nuitka-компиляцией не сработала. После слива ключей и декомпиляции автор в голосовых сообщениях переобулся с *«не опенсурс, напишешь как получится 😂»* до *«это просто калькулятор, мне не интересно, осень на дворе, я вообще отдыхаю»*.

Ну раз калькулятор — теперь он опенсурс. Пользуйтесь на здоровье.
