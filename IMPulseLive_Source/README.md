> — Прога опенсурс?  
> — *Нет конечно.*  
> — Значит будет.

Спойлер: получилось примерно за 40 минут. После чего автор побежал банить меня в своём Telegram-канале и записывать голосовые про то, что *«вообще-то это просто калькулятор, взлом мне не интересен, да и на дворе осень, погода не та, я вообще отдыхаю»*.

Разбираем, как позиционируемый как «неприступный AI-помощник для Доты на C-компиляторе» оказался банальным скриптом с открытыми ключами, бесплатным гитхабом вместо сервера и школьной математикой под капотом.

---

## Что прятали в бинарнике

Автор упаковал проект через **Nuitka**, наивно полагая, что компиляция Python в PE DLL (`.pyd`) сделает код священным граалем. В папке `_internal` лежало шесть скомпилированных библиотек:
- `dataset_updater.pyd` — синхронизация со Stratz
- `security_guard.pyd` — «продвинутая DRM-защита»
- `pick_evaluator.pyd` — «нейросетевой AI-мозг»
- `find_all_heroes.pyd` — компьютерное зрение
- `hero_grid_locator.pyd` — оверлей поверх игры
- `ui_bundle.pyd` — веб-морда (обычный HTML/JS в Base64 + zlib)

Всё это крутилось на локальном Flask-сервере и рендерилось через WebView.

## Анатомия взлома v2.0: как пала первая защита

### 1. Криптография уровня 5 класса и слитый токен Stratz

Чтобы скачивать винрейты и мету героев, софту нужен токен к GraphQL API сервиса Stratz. Разработчик решил спрятать его прямо в коде приложения.

Открываем `dataset_updater.pyd` в обычном просмотрщике строк и сразу находим шедевр:
```python
SECRET_KEY = b'IMPulseLiveSecretKey2026_DotaVision'
```
Ключ лежит открытым текстом в константах. Сам алгоритм дешифровки — это побитовый сдвиг со сложением и XOR:
```python
plain = bytes([((b - (7 + (i % 13))) % 256) ^ SECRET_KEY[i % len(SECRET_KEY)] 
               for i, b in enumerate(base64.b64decode(enc_token))])
```
Применяем формулу и получаем боевой JWT-токен Stratz:
```json
{
  "Subject": "61843030-1f9c-42ad-bdaf-9edda758b0ab",
  "SteamId": "1891508217",
  "APIUser": "true",
  "iss": "https://api.stratz.com"
}
```
Бонусом в токен намертво зашит личный **SteamID автора** (`1891508217`, он же `76561199851773945`). Передавайте привет Вадиму и добавляйте в друзья в Стиме.

### 2. «Серверная безопасность» на бесплатном GitHub

Никаких выделенных серверов у проекта нет. Вся «инфраструктура лицензирования» — это один JSON-файл на GitHub:
`https://raw.githubusercontent.com/twirlspro/IMPulse-Live/main/data/app_config.json`

В бинарнике ссылка была стыдливо прикрыта 4-байтовым XOR (`b'\x9cO\xb2\x17'`). 

Как работала эта гениальная система:
* Каждые 2 часа поток `SecurityGuard` опрашивал GitHub.
* Если автор меняет `"sync_enabled": true` на `false` — у всех юзеров врубается киллсвитч: *«Приложение временно приостановлено разработчиком»*.
* Не было интернета 48 часов (`OFFLINE_GRACE_PERIOD = 172800`)? Программа лочится и отказывается работать.
* Локальный статус лицензии хранился в `.license_cache`, зашифрованном одним байтом `0x5A`.

### 3. Где тут AI? Вскрываем алгоритм пиков

Самое смешное — внутри `pick_evaluator.pyd`. Никаких обученных моделей, нейросетей или эвристик там нет. Весь «AI» — это формула из 9 класса:

$$\text{Score} = 0.40 \times \text{Meta} + 0.25 \times \text{Synergy} + 0.25 \times \text{Counter} + 0.10 \times \text{Personal}$$

Для умного вида винрейты прогоняются через гиперболический тангенс:
```python
math.tanh((winrate - 0.5) / 0.08)
```
А «компьютерное зрение» в `find_all_heroes.py` — это обычный `cv2.matchTemplate()` из OpenCV, который сравнивает иконки героев из папочки по коэффициенту корреляции.

## 🔥 Обновление 3.0: Попытка реванша и крах «V2 защиты»

После публикации дампа автор не на шутку испугался: начал банить в своём Telegram всех подряд (даже людей, у которых просто ник похож на ник с гитхаба), записал голосовые про осеннюю хандру, а сам в панике сел пилить «большое обновление 3.0».

Спустя три дня выходит **IMPulse Live 3.0**. Разбираем, что гений нагородил на этот раз:

1. **Киллсвитч старых версий:** На GitHub в `app_config.json` он выставил `"min_version": "3.0.0"`, принудительно превратив старые официальные билды юзеров в тыкву.
2. **«Non-linear multi-stage ciphertext (V2)»:** Поняв, что открытый ключ спалили, Вадим зашил вместо строки массив целых чисел `[468, 393, 47, 106, 433, ...]` с XOR на `0x5A`, получив 16 байт энтропии (`8e d3 75 30 eb 24...`). А сам алгоритм обернул в циклический сдвиг на 3 бита (ROL 3) и прибавление `(43 + (i * 11) % 251)`.
3. **Новый Steam-аккаунт:** Чтобы не светить старый профиль, автор зарегистрировал под Stratz API новый чистый аккаунт. Но после дешифровки V2 токена мы снова достали его за пару секунд:
   ```json
   {
     "Subject": "02a28d7c-9316-4b5c-8257-791c85a29731",
     "SteamId": "1711926465",
     "APIUser": "true",
     "iss": "https://api.stratz.com"
   }
   ```
   * **Новый SteamID:** `1711926465` (SteamID64: `76561199672192193`)
   * [Новый профиль Вадима в Steam](https://steamcommunity.com/profiles/76561199672192193)
4. **«Новый» антидебаг:** Добавил `CheckRemoteDebuggerPresent()`, но соль лицензии `IMPULSE_SEC_2026` **поменять забыл**.
5. **«AI» в 3.0:** В `pick_evaluator.pyd` — **ровно 0 изменений**. Та же школьная формула.

Новая «неприступная защита V2» пала ровно за 10 минут.

## Что сделано в этом репозитории

1. **Полный отказ от `.pyd` бинарников:** Вся логика версий 2.0 и 3.0 полностью отреверсена и переписана в **100% Pure Python**. Больше нет привязки к Python 3.12 x64 — проект запускается на любой ОС и версии Python.
2. **Лицензии и киллсвитчи вырезаны:** В папке `IMPulseLive_Standalone` проверки безопасности намертво заблокированы. Программа никогда не превратится в тыкву, даже если автор снесёт свой GitHub-аккаунт.
3. **Новый рабочий токен V2 вшит намертво:** Внутри уже прошит свежий Stratz API токен от версии 3.0 как вечный резервный.
4. **Свежая база меты:** Данные патчей и винрейтов обновлены до актуального состояния.
5. **Оригинальные исходники сохранены:** В папке `IMPulseLive_Source` оставлен оригинальный код проверок для тех, кто хочет изучить, как это было устроено у автора.

## Вердикт безопасности

* **Шифрование данных (2/10):** Попытка спрятать ключ в массив чисел позабавила, но алгоритм снова симметричный и снимается анализом одной функции.
* **Архитектура лицензирования (1/10):** Всё тот же бесплатный raw JSON на GitHub. Своего бэкенда у автора как не было, так и нет.
* **Обфускация (2/10):** Nuitka спасает от школьников с декомпилятором байткода, но совершенно бессильна против базового статического анализа и инспекции памяти. Строки, сигнатуры и архитектура торчат наружу.
* **Идея софта (5/10):** Задумка оверлея нормальная, но маркетинговые сказки про «приватный AI» разбились о реальность из 4 строчек школьной математики.
